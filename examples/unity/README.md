# Fidget Unity example

Open this directory with **Unity 6000.3.18f1** (Unity 6.3).

1. Let Package Manager resolve the `com.icosa.fidget` Git dependency. The UPM
   distribution includes the C# integration and native libraries for Windows,
   macOS, Linux, Android and iOS. No Rust build or separate DLL installation is
   required to run the example.
2. Open `Assets/Example/ChangingSphere.unity` and press Play.
3. Select **Changing Sphere** and adjust the `ChangingSphere` component's radius,
   amplitude, speed and detail in the Inspector.

The scene contains a camera, the animated sphere and a material using the
package's preview shader. The material needs only positions and indices. Meshes
are generated on a worker job and applied without queuing old shape requests.

`Assets`, `Packages` and `ProjectSettings` are versioned. Unity caches, logs,
generated IDE files and player builds are ignored. The production package source
is under `unity/com.icosa.fidget` in this repository; the `upm` distribution branch
is generated by CI and contains the matching native binaries.

The default UPM package includes **iOS device** libraries. For an ARM64 iOS
simulator build, change the Git dependency revision to `upm-simulator` so Unity
installs the simulator archive instead. Both ARM64 archives must not be linked
together.

The first `upm`/`upm-simulator` publication must exist before a fresh checkout can
resolve these dependencies. Package publication is an explicit CI action, not a
per-user setup step.
